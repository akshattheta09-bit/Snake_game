SNAKE LAB

Open index.html in any modern browser. No installation or internet connection is required.

Use arrow keys, WASD, or the on-screen directional buttons. Space pauses and resumes the game. Change the pace from the dashboard. Your personal best is stored in your browser when local storage is available.

Implementation: the snake is maintained as an ordered queue of grid cells; a Set tracks occupied cells for constant-time collision lookup. Food is chosen from currently unoccupied cells.
